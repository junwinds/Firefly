# 关于我 / About Me

我会在这里分享：

- 💻 编程技术、学习笔记与项目实践
- 📝 开发中的踩坑记录与经验总结
- 🌱 生活中的点滴与思考

## 🚀 技术栈

- **框架**：Astro、TypeScript
- **前端**：Svelte、Tailwind CSS
- **部署**：Cloudflare Pages
